# knowledge/

Distilled mental models, frameworks, research artifacts, and reusable concepts — anything the user synthesizes from external sources or builds up over time.

## What goes here

- Mental models the user references repeatedly (3+ times across sessions)
- Frameworks the user has explicitly endorsed or built into their thinking
- Research findings that are generalized (not tied to one venture or client)
- External frameworks the user has adapted (with proper attribution)
- Concepts the user is actively developing

## What does NOT go here

- Actionable offers or positioning the user is using right now → that's `strategy/`
- Technical systems and architectures → that's `systems/`
- Facts about specific people or organizations → those belong in `people/` or `ventures/`
- Source summaries (one distilled article/transcript) → those belong in `summaries/`
- The user's own identity and values → that's `me/`

## Compiled truth applies here too

Concept pages with evolving understanding benefit from the [[_system/conventions/compiled-truth]] format:
- Above `---`: current distilled understanding
- Below `---`: timeline of "where this concept appeared / how thinking evolved"

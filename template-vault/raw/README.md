# raw/ — immutable source documents

Original inputs land here exactly as received — transcripts, exports, PDFs-turned-text, long documents. **Never edited, never deleted.** The assistant distills them into wiki pages (a `summaries/` page per source, plus whatever entity/journal pages the content feeds) and cites back to the raw file.

What does NOT go here: anything written by you or the assistant (→ the wiki), meeting notes you typed yourself (→ `journal/`).

Hide this folder from your Obsidian graph view — it's storage, not map.

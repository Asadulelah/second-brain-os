# Getting Started — for humans, not programmers

> You don't need to know how to code. You don't need to know what "git" or "markdown" is. If you can install an app and have a conversation, you can run this. Every step below is spelled out; nothing is assumed.
>
> Built on the Second Brain framework by [Asadulelah](https://github.com/Asadulelah).

## What you're about to get

A personal AI assistant that **remembers your life** — the people you meet, the projects you're working on, the promises you make — and keeps it all in ordinary files on your own computer, organized into a little private wiki you can browse.

You talk to it. It does the organizing. Tomorrow, next week, next month — it still knows everything you've told it.

## What you need

1. **A computer** (Windows, Mac, or Linux).
2. **A Claude account** with a paid plan (the assistant runs on Claude). Sign up at [claude.ai](https://claude.ai) if you don't have one.
3. About **15 minutes**.

That's the whole list.

---

## Step 1 — Install Claude Code

Claude Code is the app your assistant lives in. Despite the name, it's not just for coders — it's Claude with the ability to read and write files on your computer, which is exactly what a second brain needs.

- **Easiest path:** download the **Claude Code desktop app** from [claude.com/claude-code](https://claude.com/claude-code) and install it like any other app.
- Open it and sign in with your Claude account.

## Step 2 — Download this project

On this project's GitHub page ([github.com/Asadulelah/second-brain-os](https://github.com/Asadulelah/second-brain-os)):

1. Click the green **"Code"** button.
2. Click **"Download ZIP"**.
3. Unzip it anywhere.

Inside, find the folder called **`template-vault`**. That folder is your brain-to-be.

4. **Copy** the `template-vault` folder somewhere permanent — your Documents folder is perfect — and **rename it** whatever you like: `My Brain`, `Second Brain`, your call.

## Step 3 — Open your brain in Claude Code

In the Claude Code app, open the folder you just created (the same way you'd open a folder in any app: File → Open, then pick your `My Brain` folder).

## Step 4 — Say the magic words

Type this and press enter:

```
/onboard
```

Now just... talk. The assistant will:

1. **Ask what you want to call it.** Pick any name — this is *your* assistant now.
2. **Ask about you.** What you do, what you're working toward, what you want help with. Answer in your own words; it sorts everything out.
3. **Ask what you're working on and who matters** — projects, a business, key people. Rough names are fine.
4. **Ask how you want it to talk to you** — direct and challenging, warm and encouraging, purely functional.

Then it writes its own setup files from your answers and tells you it's live. **That's it — setup is over, permanently.** You never do this again.

## Step 5 — Use it (this is the whole trick)

From now on, just tell it things, the way you'd text a sharp assistant:

> *"Just got off a call with Priya — she's in for the bakery project, wants a proposal by Friday."*

It will file the meeting, create or update Priya's page, link her to the bakery project, and remember the Friday deadline. You'll see a one-line confirmation of what it saved.

And ask it things:

> *"What do I know about Priya?"* · *"What did I commit to this week?"* · *"Catch me up on the bakery project."*

It answers from your own history, with sources.

**The rule of thumb the assistant lives by:** if future-you would want to find it in three weeks, it gets filed now. You don't have to ask it to save things — saving is its default.

## Optional nice-to-haves (skip freely)

- **See your life as a map.** Install [Obsidian](https://obsidian.md) (free note app) and open your brain folder in it. Its "graph view" draws every person, project, and idea as connected dots — genuinely fun to watch grow. The assistant doesn't need this; it's a window for *you*.
- **Ask the doctor.** Type `/brain-doctor` and the assistant lists optional upgrades (like automatic memory of past chat sessions), each with the exact command to add it. Nothing on that list is required.
- **Let it clean up after itself.** Every so often, type `/brain-dream --light`. The assistant tidies its own filing — fixes links, catches duplicates — and leaves you a little report about what it did. Like letting your brain sleep.

## If something goes wrong

- **The assistant seems confused about who you are** → the setup files may not have been written; type `/onboard` again.
- **Something feels like it's not working** → type `/brain-doctor` and it will diagnose itself and tell you what's missing, in plain language.
- **You want to start over** → delete your brain folder, copy `template-vault` again, `/onboard` again. Nothing outside that folder is affected.

## One promise worth repeating

Your brain is **a folder of ordinary text files on your computer**. Nothing you file is sent to this project or anyone else. Delete the folder and it's gone; copy it to a USB stick and you've backed up your entire external memory.
